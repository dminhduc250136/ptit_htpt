# Phase 26.1 Plan 01: Migrate Payment Gateway VNPay → MoMo — payment-service core

## Tóm tắt

Thay thế hoàn toàn package VNPay bằng MoMo Developer Sandbox trong payment-service: HMAC SHA256 ký/verify đúng spec (thứ tự cố định create + lexicographic IPN), IPN handler POST JSON idempotent + amount-check + event publish RabbitMQ, gateway whitelist 2 endpoint MoMo, docker-compose env MOMO_*.

## Mục tiêu đạt được

- payment-service ký/verify HMAC SHA256 đúng spec MoMo (buildSignDataCreate fixed order + buildSignDataIpn lexicographic 13 field)
- `POST /payments/sessions provider=MOMO` gọi POST sang `https://test-payment.momo.vn/v2/gateway/api/create`, trả `payUrl`
- `POST /payments/momo/ipn` verify chữ ký + idempotent + amount-match + phát PaymentSucceeded/Failed, trả HTTP 204
- `GET /payments/momo/return` chỉ verify để hiển thị FE, không update DB
- MoMo IPN/return bypass ApiResponseAdvice envelope
- Gateway whitelist `/api/payments/momo/ipn` (POST) + `/api/payments/momo/return` (GET) cho MoMo gọi không cần JWT
- Exchange `payment.events` RabbitMQ giữ nguyên + PaymentEventEnvelope giữ shape, rename field `vnpTransactionNo` → `paymentTransactionNo`
- Package `vnpay/` + 2 test VNPay biến mất; payment-service zero VNPay references
