# Phase 27 — UI Design Contract

> Visual and interaction contract cho 3 trang auth nhẹ: `/verify-email`, `/reset-password`,
> `/forgot-password` + link "Quên mật khẩu?" trong trang login.
> Phase này backend-heavy. UI contract proportionate — không over-specify.
> Generated by gsd-ui-researcher. All copy in Vietnamese.

---

## Scope Note

Trang frontend mới trong phase này:

| Trang | Mô tả |
|-------|-------|
| `/forgot-password` | Form nhập email, gửi yêu cầu reset, hiện "kiểm tra hộp thư" |
| `/verify-email` | Đọc `?token`, gọi GET /auth/verify-email, hiện kết quả: thành công / hết hạn / không hợp lệ |
| `/reset-password` | Đọc `?token`, form mật khẩu mới + xác nhận, gọi POST /auth/password/reset |
| Login page (sửa nhỏ) | Thêm link "Quên mật khẩu?" dưới field password (đã có `styles.forgotLink` trong `page.module.css`) |

### `/forgot-password` — Form nhập email

```
[formHeader]
  h1: "Quên mật khẩu?"
  p:  "Nhập email đăng ký, chúng tôi sẽ gửi link đặt lại mật khẩu"

[form]
  Input email (type="email", icon envelope SVG, fullWidth)
  Button submit (type="submit", size="lg", fullWidth, loading state)

[switchAuth]
  "Nhớ mật khẩu rồi?" <Link href="/login">Đăng nhập</Link>
```

**States:**
- Idle: form rỗng, nút active
- Loading: nút `loading={true}` + spinner
- Success: form ẩn, hiện panel xác nhận (xem Copywriting Contract)
- Error (API): Banner component trên form

### `/verify-email` — Status card (không phải form)

```
[statusCard]  — max-w 440px, surface-container-lowest, radius-2xl, shadow-xl
  [icon]    — 64x64px circle (thành công: xanh lá / hết hạn + không hợp lệ: đỏ)
  [h1]      — tiêu đề theo trạng thái (xem Copywriting Contract)
  [p]       — mô tả theo trạng thái
  [Button]  — CTA theo trạng thái (xem Copywriting Contract)
```

**States:**
- Loading: spinner nhỏ (24px) giữa trang — dùng CSS animation `pulse` đã có
- Success: icon check circle (#16a34a), tiêu đề xanh, CTA "Đến trang đăng nhập"
- Expired: icon clock (#ba1a1a), tiêu đề đỏ, CTA "Gửi lại email xác minh"
- Invalid: icon X circle (#ba1a1a), tiêu đề đỏ, CTA "Quay lại trang chủ"

Icon states dùng inline SVG (24x24px) trong circle container 64x64px:
- Success: `color: #16a34a`, background `rgba(22, 163, 74, 0.1)`
- Error/Expired: `color: var(--error)` (#ba1a1a), background `var(--error-container)` (#ffdad6)

## Interaction Contracts

### Form submission flow (chung cho 2 trang form)

1. User submit → validate client-side → nếu lỗi: hiện `Banner` + field error, DỪNG
2. Nếu valid: set `loading={true}` → gọi API
3. API success → hiện success panel (không navigate, replace form bằng success state)
4. API error (4xx/5xx) → set `loading={false}` → hiện `Banner` với message lỗi

### `/verify-email` flow

1. Component mount → đọc `searchParams.get('token')`
2. Nếu không có token: hiện "Invalid" state ngay (không gọi API)
3. Nếu có token: hiện spinner → gọi `GET /auth/verify-email?token=...`
4. Response 200: hiện Success state
5. Response 400/410 (expired): hiện Expired state
6. Response 400 (invalid): hiện Invalid state
7. Response 5xx: hiện Invalid state (fallback an toàn)

### Password strength (chỉ client-side, minimal)

- Validate độ dài >= 6 ký tự (giống register page)
- Không hiện password strength meter — ngoài scope (keep it simple)

### Accessibility requirements

- `role="alert"` + `aria-live="assertive"` trên Banner — đã có trong Banner component
- `type="submit"` trên form button — đảm bảo Enter key submit form
- Label liên kết đúng với Input qua `label` prop
- `:focus-visible` outline — đã có trong globals.css (`--primary-container`)
- Spinner có `aria-label="Đang xử lý"` hoặc `aria-busy="true"` trên form element
