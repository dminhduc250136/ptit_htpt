## Tasks

### T-24-04-01: Error advice DATABASE_UNAVAILABLE

- Cho mỗi service backend (user/product/order/inventory/payment), trong package `*.web` hoặc `*.config` tạo (hoặc extend) `GlobalExceptionHandler`:
  ```java
  @ExceptionHandler({ org.springframework.transaction.CannotCreateTransactionException.class,
                     org.hibernate.exception.JDBCConnectionException.class })
  public ResponseEntity<ApiErrorResponse> handleDbDown(Exception ex, HttpServletRequest req) {
      return ResponseEntity.status(503).body(
          ApiErrorResponse.of("DATABASE_UNAVAILABLE", "Service database is temporarily unavailable", ...));
  }
  ```
- Reuse `ApiErrorResponse` class pattern hiện có (mỗi service có 1 dạng). Nếu chưa có → minimal POJO `{code, message, traceId, timestamp}`.
- Nếu service đã có `ControllerAdvice` (vd order-svc) → chỉ thêm method mới, KHÔNG sửa method có sẵn.
