# Phase 24 — Plan 01: docker-compose tách postgres per service

**Phase:** 24 Database Per Service
**Plan:** 01 of 04
**Depends on:** none (entry plan)

## Goal

Refactor `docker-compose.yml` từ 1 postgres container shared → 6 postgres container riêng (`postgres-user`, `postgres-product`, `postgres-order`, `postgres-inventory`, `postgres-payment`, `postgres-chat`). Bỏ port host mapping cho các postgres container. Volume riêng từng service. Bỏ volume cũ `tmdt-pgdata`.

Reference: 24-CONTEXT.md D-01, D-02 (lưu ý: nếu Phase 23 đã merge → thêm `postgres-notification`; check git trước), D-03, D-04, D-05, D-09 (postgres-chat), D-11 (depends_on từng service trỏ postgres riêng), D-12 (healthcheck).

## Tasks

### T-24-01-02: Viết docker-compose.yml mới

- 6 postgres service (hoặc 7 nếu có notification):
  ```yaml
  postgres-user:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: user_svc
      POSTGRES_USER: user_svc
      POSTGRES_PASSWORD: user_svc_pw
    volumes:
      - pgdata-user:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U user_svc -d user_svc"]
      interval: 5s
      timeout: 5s
      retries: 10
  ```
  Tương tự cho product/order/inventory/payment/chat (db/user/password trùng tên service, password suffix `_pw`).
- **KHÔNG** thêm `ports:` cho postgres container (D-04).
- Backend service `depends_on` chỉ postgres của riêng nó:
  - `user-service` depends on `postgres-user` (`condition: service_healthy`).
  - `product-service` → `postgres-product`. Etc.
- Backend service env vars đổi:
  - `user-service`: `DB_HOST: postgres-user`, `DB_NAME: user_svc`, `DB_USER: user_svc`, `DB_PASSWORD: user_svc_pw`.
  - Tương tự 5 service kia.
- `frontend` env: `DB_HOST: postgres-chat`, `DB_NAME: chat_svc`, `DB_USER: chat_svc`, `DB_PASSWORD: chat_svc_pw`. Giữ `API_GATEWAY_URL` + `ANTHROPIC_API_KEY` + `JWT_SECRET` như cũ.
- `volumes:` section: liệt kê `pgdata-user`, `pgdata-product`, `pgdata-order`, `pgdata-inventory`, `pgdata-payment`, `pgdata-chat` (+ `pgdata-notification` nếu D-02 áp dụng). XÓA `tmdt-pgdata`.
- `api-gateway` giữ nguyên (Phase 25 mới sửa). Frontend giữ port 3000:3000.

### T-24-01-03: Cleanup runtime + smoke

- `docker compose down -v` để xóa volume cũ.
- `docker compose up -d` — verify tất cả container Up + healthy bằng `docker compose ps`.
- `docker compose logs postgres-user | tail -5` để xác nhận DB init OK. Lặp cho 5 postgres còn lại.

## Acceptance

- `docker-compose.yml` chỉ còn `api-gateway`, `frontend`, 6-7 postgres-* và 6 backend service.
- `docker compose ps` cho thấy tất cả postgres-* healthy.
- `docker compose port postgres-user 5432` trả error (không có port mapping) → xác nhận D-04.
- Không còn reference `tmdt-pgdata` ở compose hoặc README.
