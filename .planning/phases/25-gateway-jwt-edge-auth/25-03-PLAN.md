# Phase 25 — Plan 03: FE bỏ X-User-Id thủ công, dựa Bearer

**Phase:** 25
**Plan:** 03 of 05
**Depends on:** 25-02

## Goal

Refactor FE services không gửi `X-User-Id` thủ công nữa (backend nhận trusted header từ gateway). Cập nhật type generated nếu cần. Pages tương ứng (`checkout`) bỏ truyền `user?.id`.

Reference: 25-CONTEXT.md D-14, D-15, D-16.

## Tasks

### T-25-03-01: services/cart.ts

- Mở `sources/frontend/src/services/cart.ts`.
- Xóa hàm `cartUserHeaders(userId)` (line ~127-130).
- Mỗi call `httpGet/Post/Delete/Patch` đang pass `...cartUserHeaders(userId)`: xóa argument đó. Bearer đã auto-attach qua `services/http.ts`.
- Xóa parameter `userId` khỏi các function nếu chỉ dùng cho header (vd `mergeCart`, `fetchCart`, `addToCart`).
- Update mọi call-site trong `app/**` và `components/**` (grep `from 'services/cart'` hoặc `@/services/cart`).

### T-25-03-02: services/orders.ts

- Mở `sources/frontend/src/services/orders.ts`.
- Xóa `orderUserHeaders(userId)` (line ~40).
- Bỏ argument `userId` ở mọi function (vd `createOrder`, `listOrders`, `getOrder`).
- Update call-site: `app/checkout/page.tsx` line ~187 `createOrder(..., user?.id)` → `createOrder(...)`. Grep tất cả call để chắc chắn.

### T-25-03-03: services/coupons.ts

- Mở `sources/frontend/src/services/coupons.ts`.
- Xóa block `if (userId) headers['X-User-Id'] = userId` (line ~22).
- Xóa param `userId` khỏi signature.
- Update call-site (checkout).

### T-25-03-04: services/http.ts — 401 expired handling

- Mở `sources/frontend/src/services/http.ts`.
- Nếu chưa có: thêm logic — khi response 401 + body có `code === "AUTH_TOKEN_EXPIRED"` → call `localStorage.removeItem('auth.token')` + `window.location.assign('/login?next=' + encodeURIComponent(window.location.pathname))`.
- Wrap behind `typeof window !== 'undefined'` để SSR-safe.

### T-25-03-05: types/api/orders.generated.ts

- Để nguyên (D-15) — field `"X-User-Id"?: string` là optional, FE không gửi nữa → không break compile.
- Nếu có script `npm run gen:types` hoặc `openapi-typescript` → defer regenerate sang phase sau (note vào SUMMARY).

### T-25-03-06: TypeScript check

- `cd sources/frontend && npm run typecheck` (hoặc `tsc --noEmit`).
- Fix bất kỳ type error nào do remove param `userId`.
