# Phase 25 — Plan 01: JwtVerifier + JwtAuthenticationFilter ở api-gateway

**Phase:** 25 Gateway JWT Edge Authentication
**Plan:** 01 of 05
**Depends on:** none (entry plan)

## Goal

Triển khai `JwtVerifier` (parse + verify HS256) và `JwtAuthenticationFilter implements GlobalFilter, Ordered` trong api-gateway. Filter: parse Bearer → verify → strip client-supplied `X-User-Id`/`X-User-Roles`/`X-Request-Id` → inject trusted header. Allow-list public + admin path config-driven trong `application.yml`.

Reference: 25-CONTEXT.md D-01, D-02, D-03, D-04, D-05, D-06, D-07, D-08.

### T-25-01-04: JwtAuthenticationFilter

- Tạo `apigateway/auth/JwtAuthenticationFilter.java`:
  ```java
  @Component
  public class JwtAuthenticationFilter implements GlobalFilter, Ordered {
      private final JwtVerifier verifier;
      private final AuthProperties props;
      private final AntPathMatcher matcher = new AntPathMatcher();
      // constructor injection
      @Override public int getOrder() { return -100; }  // chạy trước RequestIdFilter
      @Override public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
          var req = exchange.getRequest();
          var path = req.getPath().value();
          var method = req.getMethod();
          // 1. Strip client-supplied trust headers
          var mutated = req.mutate()
              .headers(h -> { h.remove("X-User-Id"); h.remove("X-User-Roles"); h.remove("X-Username"); })
              .build();
          // 2. Parse Bearer (may absent)
          String bearer = req.getHeaders().getFirst(HttpHeaders.AUTHORIZATION);
          VerifiedClaims claims = null;
          if (bearer != null && bearer.startsWith("Bearer ")) {
              try { claims = verifier.verify(bearer.substring(7)); }
              catch (TokenExpiredException e) { return reject(exchange, 401, "AUTH_TOKEN_EXPIRED", "Token expired"); }
              catch (TokenInvalidException e) { return reject(exchange, 401, "AUTH_TOKEN_INVALID", "Token invalid"); }
          }
          boolean publicEp = isPublic(method, path);
          boolean adminEp  = isAdmin(path);
          if (!publicEp && claims == null) return reject(exchange, 401, "AUTH_TOKEN_MISSING", "Authentication required");
          if (adminEp && (claims == null || !claims.roles().contains("ADMIN")))
              return reject(exchange, 403, "AUTH_ROLE_DENIED", "Admin role required");
          // 3. Inject trusted
          if (claims != null) {
              var c = claims;
              mutated = mutated.mutate()
                  .header("X-User-Id", c.userId())
                  .header("X-User-Roles", String.join(",", c.roles()))
                  .header("X-Username", c.username() != null ? c.username() : "")
                  .build();
          }
          return chain.filter(exchange.mutate().request(mutated).build());
      }
      // helpers: isPublic / isAdmin / reject
  }
  ```
- `reject()` helper: build `ApiErrorResponse` JSON bằng `ObjectMapper` injected, set status + content-type, `exchange.getResponse().writeWith(...)`. Reuse pattern `GlobalGatewayErrorHandler` hiện có.
- `isPublic()`: loop `props.publicEndpoints()` — match nếu `method == HttpMethod.valueOf(ep.method())` AND `matcher.match(ep.pattern(), path)`.
- `isAdmin()`: loop `props.adminPathPatterns()` — match bất kỳ.
