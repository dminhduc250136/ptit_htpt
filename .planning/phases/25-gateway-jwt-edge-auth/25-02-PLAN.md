# Phase 25 — Plan 02: Error contract AUTH_* + docker-compose bỏ port mapping

**Phase:** 25
**Plan:** 02 of 05
**Depends on:** 25-01

## Goal

- Đảm bảo response 401/403 từ filter follow format `ApiErrorResponse` chuẩn (reuse class hiện có ở gateway package).
- Bỏ `ports:` mapping của 6 backend service trong `docker-compose.yml` (giữ gateway 8080 + frontend 3000 + postgres internal).

Reference: 25-CONTEXT.md D-09, D-10, D-11, D-12, D-13.

## Tasks

### T-25-02-01: Audit ApiErrorResponse hiện tại

- Đọc `sources/backend/api-gateway/src/main/java/com/ptit/htpt/apigateway/gateway/ApiErrorResponse.java`.
- Xác nhận có constructor / builder phù hợp để filter tạo response. Nếu cần, thêm static factory `ApiErrorResponse.of(String code, String message, String traceId)`.

### T-25-02-02: Helper `AuthErrorResponseWriter`

- Tạo `apigateway/auth/AuthErrorResponseWriter.java` — Spring component:
  - Inject `ObjectMapper`.
  - Method `Mono<Void> write(ServerWebExchange exchange, int status, String code, String message)`:
    1. Tạo `ApiErrorResponse` với traceId từ MDC (hoặc `exchange.getRequest().getHeaders().getFirst("X-Request-Id")`).
    2. Serialize bằng ObjectMapper → bytes.
    3. `exchange.getResponse().setStatusCode(HttpStatus.valueOf(status))`.
    4. Set header `Content-Type: application/json`.
    5. Return `exchange.getResponse().writeWith(Mono.just(bufferFactory.wrap(bytes)))`.
- Refactor Plan 01 `JwtAuthenticationFilter.reject(...)` → delegate sang writer này.

### T-25-02-03: docker-compose bỏ port mapping backend

- Mở `docker-compose.yml`. Trong 6 backend service (`user-service`, `product-service`, `order-service`, `payment-service`, `inventory-service`, `notification-service`), XÓA toàn bộ block:
  ```yaml
  ports:
    - "808X:8080"
  ```
- GIỮ:
  - `api-gateway: 8080:8080`.
  - `frontend: 3000:3000`.
- Postgres container đã không expose port từ Plan 24-01.

### T-25-02-04: Verify isolation

- `docker compose up -d --build api-gateway user-service` (hoặc up full).
- `curl http://localhost:8081/users` → "connection refused" hoặc "no route". Document trong VERIFICATION (Plan 05).
- `curl http://localhost:8080/api/users/me` không Bearer → 401 JSON `{"code":"AUTH_TOKEN_MISSING",...}`.
- `curl http://localhost:8080/api/products` (public, không Bearer) → 200.

## Acceptance

- `JwtAuthenticationFilter` reject → response body là JSON `ApiErrorResponse` đầy đủ.
- `docker-compose.yml` chỉ còn `8080:8080` và `3000:3000` (+ postgres internal).
- Curl `localhost:8081-8086` không thể connect.
